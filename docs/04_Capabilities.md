# Purpose

This document defines the capabilities of Alfa COS.

Every new feature must belong to one of these capability groups.

---

# 1. Conversation

Status: V1

Capabilities

- Natural conversation
- Multi-language support
- Context-aware responses
- Follow-up conversations
- Voice conversations

---

# 2. Memory

Status: V1

Capabilities

- Remember user preferences
- Remember projects
- Remember goals
- Remember conversations (important only)
- Forget information on user request

---

# Capability Rule

Every capability must:

- Respect user privacy.
- Be modular.
- Be replaceable.
- Require permissions where necessary.
- Follow Alfa COS Principles.
